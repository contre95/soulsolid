Find albums that are missing tracks. Each album is looked up on Deezer or MusicBrainz for its official track count and compared with the tracks in your library. The result is shown on the album page and listed below.

Only exact title and artist matches are used, so a deluxe or remastered edition may report a different track count than yours. Use Set count on the album page to correct it. Lookups are rate limited, so a large library takes a while.
