Merge Metadata

Find artists, albums and genres that are the same but spelled differently — case, punctuation, accents or spacing. Pick the name to keep and merge the rest into it. Changes are applied to the library and written back to the audio file tags. Also find duplicate tracks — the same recording stored in more than one file (e.g. a FLAC and an MP3), detected by AcoustID. Merging tracks permanently deletes the checked files from disk; Keep leaves every file in place and records the group as intentional duplicates (database only).

File paths are not updated after merge. Run /analyze/files afterwards to recompute paths based on the updated metadata.

Tracks

On duplicate track finding, we use AcoustID. We don't do this on import, since that would make us dependent on a third-party service in order to onboard a track — there we check Chromaprint directly, which already gives us a very good idea if the song is the same. But slight variations in the same recording (e.g., different file encodings, bitrates, minor edits, noise, or compression artifacts) can produce slightly different Chromaprints — for that we can merge based on AcoustID, the crowdsourced ID a song has.

Click Scan to find duplicate tracks — files sharing the same AcoustID. Merging deletes the duplicate files from disk.
